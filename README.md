# Global Logistics — Logistics Management System

> Legacy full-stack project retained as a supporting portfolio repository.

A Node.js/Express logistics management application with a web interface and MongoDB-backed domain models.

## Scope
- User registration and authentication
- Shipment creation and management
- Shipment tracking
- Billing and invoices
- Support tickets
- Administrative workflows
- Rate limiting and security middleware
- Email and payment integration boundaries

## Stack
- Node.js
- Express
- MongoDB / Mongoose
- HTML, CSS and JavaScript
- JWT-based authentication
- dotenv-based configuration

## Repository status
This is an older project and is **not one of my primary portfolio projects**. It is kept public as evidence of earlier application-development work.

The repository is not presented as production-ready. Configuration, dependency versions, test coverage, deployment automation and operational hardening would need further work before production use.

## Local configuration
Environment-specific values must be supplied locally. Do not commit .env files or credentials.

The committed .env file has been removed from the repository. If any real credential was ever used in that file, rotate it immediately.
